# 🟢 IDP

* <mark style="color:purple;background-color:purple;">**SSO:**</mark>
  * <mark style="color:purple;background-color:purple;">**corporate identity provider**</mark>
  * <mark style="color:purple;background-color:purple;">**Contains all the user id and password for all the user and all systems**</mark>
* <mark style="color:purple;background-color:purple;">**SSO has a trusted relationship with the systems**</mark>
* <mark style="color:purple;background-color:purple;">**SSO issues SAML token**</mark>&#x20;
* <mark style="color:purple;background-color:purple;">**Application validates token**</mark>
* <mark style="color:purple;background-color:purple;">**BTP uses SAP IDP, this can be configured to use other IDP also**</mark>
* <mark style="color:purple;background-color:purple;">**We need a backing service of xsuaa**</mark>
