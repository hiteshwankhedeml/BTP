# 🟢 Why we need frameworks to develop apps?

* Framework is a collection of libraries, classes which contains ready to use patterns and code
* It standardizes our complicated development in real-time
* It outlines the golden rules which can be applied in the development of our application
* <mark style="color:purple;background-color:purple;">**There are many tasks which will be taken away from the developer so the developer can focus on the domain knowledge and build applications by writing minimal amount of code**</mark>
* Example:
  * CAPM
  * RAP
  * SAP BOPF
  * Node - Loopback
  * express
  * nginex
