# 🟢 Subscription based services

* Calles Software as a service
* <mark style="color:purple;background-color:purple;">**You subscribe a service, and it gives a URL using which we can access the service**</mark>
* Using the application we can access the service
* This is how saas application like successfactors, s/4 cloud works
* <mark style="color:purple;background-color:purple;">**Enabled at sub account level, independent of the environment**</mark>
* You don't need cloud foundry to be enabled for this
