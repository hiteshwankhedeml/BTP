# ✈️ Spring framework

* Framework used by java programmers
* To develop complex applications — UI based, cloud microservice based with security, cloud native apps, web portals etc.
  * Spring Web ⇒ to build web based application
  * Spring Boot ⇒ to initialize the projects faster
  * Spring MVC&#x20;

**Advantages:**

1. Takes away lots of work ⇒ creating and managing the object of the classes&#x20;
2. It provides runtime environment for complex microservice environment
3. Supports lifecycle methods ⇒ automatic event triggers
4. All the objects are loosely coupled
