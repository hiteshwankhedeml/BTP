# BAS

* Development environment available on SAP BTP
* Can be setup as a Free tier service by checking the free plan
* Provides a dev space for developers to create private workspace to have predefined dependencies installed for creating particular type of applications
* It incurs cost, so we do developemnt in VS Code
* Below roles should be assigned for BAS to work for a user:
  * Admin Role, Developer Role, Extension Deployer
