# 🟢 CF Commands

* command prompt ⇒ <mark style="color:purple;background-color:purple;">**cf login**</mark>
* for 1st time it will ask for URL
* The URL can be get from subaccount ⇒ cloud foundry environment
* Provide the URL
* Provide the mail and password
* cf apps ⇒ to see the list of apps
* <mark style="color:purple;background-color:purple;">**cf buildpacks**</mark> ⇒ to get the list of buildpacks available
* cf logs <\<app\_name>> ⇒ to check the logs
* cf scale <\<app\_name>> -i 2 ⇒ to scale to 2 containers ⇒ Horizontal scaling
* <mark style="color:purple;background-color:purple;">**cf scale**</mark> <\<app\_name>> -m 1024M ⇒ to scale t ⇒ Vertical scaling
* <mark style="color:purple;background-color:purple;">**cf push**</mark>
