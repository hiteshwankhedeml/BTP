# CF Commands

* command prompt ⇒ cf login
* for 1st time it will ask for URL
* The URL can be get from subaccount ⇒ cloud foundry environment
* Provide the URL
* Provide the mail and password
* cf apps ⇒ to see the list of apps
* cf buildpacks ⇒ to get the list of buildpacks available
* cf logs <\<app\_name>> ⇒ to check the logs
* cf scale <\<app\_name>> -i 2 ⇒ to scale to 2 containers ⇒ Horizontal scaling
* cf scale <\<app\_name>> -m 1024M ⇒ to scale t ⇒ Vertical scaling
