# 🟢 Tools and Installation

1. **JRE and node (Runtime):**

* JDK&#x20;
  * Always download from oracle site
  * java - version ⇒ to check the version ⇒ 11.0.4
* Node JS
  * nodejs 18 download
  * node -v ⇒ to check the version

2. <mark style="color:purple;background-color:purple;">**CF CLI (Command line interface) to communicate with SAP BTP:**</mark>

* Install from cloud foundry website
* cf --help ⇒ to check version

3. **Development tools:** - VS Code + Extension (Java extension, spring extension, fiori extension and sap cds extension)

* Install VS Code
* workspace is folder in computer
* Extension ⇒ java extension, spring boot extension, fiori extension pack, sap cds language support

4. **Install postgresql in local:**

* Download from postgresql
* pgAdmin tool will get installed using which we can connect to DB
