# 🟢 CI/CD

* <mark style="color:purple;background-color:purple;">**Developer commits the code to github**</mark>
* <mark style="color:purple;background-color:purple;">**A pipeline will run**</mark>
* <mark style="color:purple;background-color:purple;">**For this we will be using SAP CI/CD service**</mark>
* <mark style="color:purple;background-color:purple;">**Whenever code is pushed to git ⇒ it will raise event(web hook)**</mark>
* <mark style="color:purple;background-color:purple;">**This event will be sensed by CI/CD**</mark>
* <mark style="color:purple;background-color:purple;">**Here there will be pipeline which will deploy the app to BTP**</mark>
