# 🟢 HANA vs HDI

* <mark style="color:purple;background-color:purple;">**SAP HANA: the database (in-memory DBMS) — where data lives and SQL runs.**</mark>
* HDI: how app-owned objects are packaged, deployed, and isolated inside HANA.
* You still define HANA objects; HDI puts them in a container and manages lifecycle.
* Classic HANA: users/schemas/roles you manage more directly.
* <mark style="color:purple;background-color:purple;">**HDI:**</mark> container + technical users + <mark style="color:$danger;background-color:purple;">**controlled privilege**</mark><mark style="color:$danger;background-color:purple;">s</mark> for cloud-style apps.
